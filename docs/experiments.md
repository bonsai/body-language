# 実験計画（初期案）

## 研究質問

1. ダンス、ジェスチャー、手話、動物行動を、共通の観察記述と領域固有の意味記述で表現できるか。
2. 映像の動きだけを使う場合と、音声・状況・相手の反応を加える場合で、解釈の正確さはどう変わるか。
3. 観察と解釈を分離した構造化データは、自然言語だけの指示に比べて再現性や誤りの検出を改善するか。
4. AIは根拠が不足しているときに、意味を断定せず「不明」と回答できるか。

## 比較条件

- A: 動画・動作情報のみ
- B: 動作情報 + 音声
- C: 動作情報 + 音声 + 場面の説明
- D: 動作情報 + 音声 + 場面 + 相手の観察された反応
- E: 上記を観察と解釈に分けた構造化レコードとして入力

条件間では、対象データと評価基準をできるだけ揃える。各条件で使ったモデル、プロンプト、前処理、バージョンを記録する。

## 評価指標

- **動作記述の一致度:** 人間の注釈と、軌跡・反復・姿勢などの記述がどの程度一致するか
- **意味推定の精度:** 根拠があるラベルに対する適合率・再現率など
- **注釈者間一致度:** 人間同士でも解釈が割れる程度を把握する
- **不確実性の較正:** 高い確信度が高い正答率と対応するか
- **保留の適切さ:** 正解を決められない例で、断定を避けられるか
- **再現性:** 同じ入力・設定で結果がどの程度安定するか
- **コスト:** 処理時間、計算資源、注釈工数

意味の正解ラベルが曖昧な領域では、単一の「正解」を無理に作らず、複数注釈者の見解や根拠を保持する。

## データ収集と倫理

- 利用許諾とライセンスを確認した映像・音声だけを使う。
- 個人が識別できる映像では、同意、目的、保存期間、アクセス制御を検討する。
- 手話データでは、当事者・言語コミュニティの知見と適切な注釈方法を重視する。
- 動物行動では種、環境、観察条件を記録し、人間の意図を安易に投影しない。
- 学習データと評価データの混入を防ぐ。
- 小規模な探索実験の結果を一般的な理解能力の証明としない。

## 最小実験（MVP）

1. 権利上問題のない短いサンプルを少数選ぶ。
2. 2名以上で観察可能な動作と解釈仮説を別々に注釈する。
3. 構造化前後でAIの説明を比較する。
4. 間違いだけでなく、根拠のない断定と適切な保留も評価する。
5. 結果、制約、再現手順を記録する。
