# 身体表現オントロジー（初期案）

## 目的

身体表現の記述に共通する最小限の語彙を定義する。映像から直接観察できる事実、文脈情報、人間やAIによる解釈を混同しない。

## 中核概念

| 概念 | 意味 | 例 |
|---|---|---|
| Agent | 動作を行う主体 | 人、鳥、複数人 |
| Action | 観察された動作 | 手を上げる、旋回する |
| Trajectory | 時間に沿った位置・方向の変化 | 八の字状の軌跡 |
| Timing | 持続時間、テンポ、反復 | 3回反復 |
| Posture | 身体各部の配置 | 腕を広げ、前傾する |
| Gaze | 視線方向や注視対象 | 相手を見る |
| Vocalization | 発声・歌・音響特徴 | 呼び声、歌唱 |
| Target | 動作や合図が向けられる対象 | 相手、物体、不明 |
| Context | 場所、状況、文化、活動など | 舞台、会話、繁殖期 |
| Response | 観察された相手の反応 | 接近、回避、応答 |
| Interpretation | 行動の意味・機能についての仮説 | 求愛の可能性 |
| Evidence | 解釈を支える観察・資料 | 映像、注釈、研究資料 |
| Uncertainty | 観測・解釈に伴う不確実性 | 遮蔽、複数の解釈 |

## 重要な区別

### 観察（Observation）

センサーや注釈者が記録した内容。例：「手が肩より高い位置に上がった」「身体の中心点が曲線を描いて移動した」。

### 解釈（Interpretation）

観察と文脈から導いた仮説。例：「相手への合図かもしれない」。解釈は観察データそのものではなく、根拠と確信度を持つ仮説として扱う。

### 意図（Intent）

主体が何を意図していたかという推定。外から直接観察できるとは限らず、自己報告や文脈などの追加証拠が必要になる。

## 共通層と固有層

共通層は時刻、主体、身体部位、軌跡、文脈、根拠、確信度などを提供する。固有層は、手話の言語構造、特定の舞踊の様式、種ごとの行動レパートリーなどを記述する。共通層は各体系の意味を置き換えるものではない。

## 注釈ルール

1. 可能なら観察を解釈より先に記録する。
2. 不明な対象や意味は null / unknown とする。
3. 複数の解釈が妥当なら、ひとつに決めず仮説を並べる。
4. 確信度は動作検出と意味解釈で別々に保持する。
5. 注釈者、資料、時刻範囲、利用条件を記録する。
6. 文化的意味や動物行動の機能を断定する場合は根拠資料を明示する。
