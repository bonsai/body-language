# 身体は言語である — AIは踊りを理解できるか

ダンス、ジェスチャー、手話、歌、求愛、威嚇。人や動物は、言葉だけでなく、身体の動き・リズム・視線・姿勢・声・空間の使い方によって情報を伝える。このリポジトリでは、それらをAIがどこまで観察・解釈できるのかを、エッセイと小さな実験を通じて考える。

## 中心となる問い

**AIは身体の動きを検出できることと、その意味を理解できることを、どう区別できるか。**

動作の形を分類するだけでは、意図や意味を理解したことにはならない。同じ動きでも、状況、文化、相手、直前の出来事によって意味が変わりうる。観察できた事実と、そこから推測した解釈を分けて記録し、解釈の確かさを検証する。

## 扱うテーマ

- ダンスとリズム：身体で何を伝え、何を共有するのか
- 八の字ダンス：軌跡・重心・反復・リズムをどう記述するか
- ジェスチャー：指示、挨拶、感情表現、会話中の身振り
- 手話：独自の文法を持つ自然言語として尊重し、単なるジェスチャーに還元しない
- 求愛ダンスと威嚇：動物行動の機能を、擬人化せず文脈と証拠から考える
- 歌と身体：声、呼吸、姿勢、動き、リズムの関係
- 身体表現とAI：観察、仮説、文脈、評価、誤解の扱い

## 方法

1. 動画・音声・姿勢などから観察可能な特徴を記録する。
2. 観察事実と意味の解釈を別のフィールドに分ける。
3. 文脈や相手の反応を加えた場合に、解釈がどう変わるか比較する。
4. 人による注釈とAIの推定を比較し、不確実性や誤りを記録する。
5. 再現可能なデータ形式と評価手順を整える。

## 原則

- **観察と解釈を分ける。** 「八の字の軌跡が見えた」は観察、「求愛の意図がある」は仮説。
- **信頼度を分ける。** 動作検出の確信度と意味解釈の確信度は同じではない。
- **言語ごとの構造を尊重する。** 手話を一般的な身振り辞書だけで表現しない。
- **文化・状況・個人差を扱う。** ひとつの動きに普遍的な意味を決めつけない。
- **プライバシーと権利を守る。** データの利用条件、同意、匿名化を確認する。
